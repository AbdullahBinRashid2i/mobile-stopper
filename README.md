# Steady — Student Digital Well-Being Prototype

A small, private web prototype for students to pause, choose a next step, and shape their own focus and bedtime routines.

## Open the app

Open `index.html` in a modern browser. It runs locally without an account or server.

## What's included

- A small-step task starter
- An optional interruption-boundary checklist
- A flexible focus timer
- Bedtime routine prompts
- A private check-in
- A prompt to contact a trusted person or campus support

No sign-in, tracking, scores, or personal data collection.
